# Support

MCP OpenAPI Creator Kit is a community project and is not an official Microsoft
product. It is provided without a support SLA.

- Use GitHub Issues for reproducible bugs, feature requests, and documentation
  problems.
- Use GitHub Discussions for design questions and usage guidance when enabled.
- Use private vulnerability reporting for security issues; see `SECURITY.md`.

Before opening an issue, include the gateway profile, operating system, Python
version, failing command, and sanitized output. Never include credentials,
subscription keys, tenant identifiers, or customer data.
