# Code of Conduct

## Our standard

We are committed to a respectful, inclusive, and professional community.
Contributors must communicate constructively, welcome different perspectives,
and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
intimidation, publishing private information, and sustained disruption of
project discussions.

## Enforcement

Report conduct concerns privately through the repository's GitHub private
vulnerability reporting channel. Project maintainers may edit or remove
comments, reject contributions, or restrict participation when behavior is
inconsistent with this standard.

Reports will be handled as confidentially as practical. Good-faith reports will
not result in retaliation.
